1.4.5

Beach Episode album integration

Jul 13, 2026

If you also play with the Beach Episode mod, AliveNpcs now opens its achievement album and records the actions that succeed there.

  • The AliveNpcs Hub shows the Beach Episode Album button only when SMAPI has loaded Beach Episode.
  • The album button and the Personality Editor button can show up together, and each one opens the right screen.
  • When a Beach Episode action is applied successfully in the game, AliveNpcs records the achievement in the album.
  • Only three actions count: watching the parrots, setting up a picnic and taking a photo.
  • Actions that failed, got no response or come from other packs don't unlock achievements.
  • Both mods keep working on their own. AliveNpcs doesn't require Beach Episode.
  • If your Beach Episode version is old or incompatible, the Hub stays open and the problem shows up as a warning in the SMAPI log.
  • If recording the achievement fails, the action AliveNpcs already applied still stands.
1.4.4

Personality Editor integration

Jul 10, 2026

AliveNpcs now has an official integration with the Personality Editor, the companion mod that lets you change villagers' personalities. The editor follows the same compatibility and protection rules as AliveNpcs itself.

  • The editor lists the NPCs that can get a personality of your own in the current save: the base game villagers and the NPCs from mods you allowed.
  • NPCs blocked by your compatibility settings or by the community AI opt-out list don't show up for editing.
  • The editor keeps working even if you rename its folder.
  • The editor's data file has to be named custom_personalities.json. The default location is still Mods/AliveNpcsPersonalityEditor/custom_personalities.json.
  • Restoring the default in the editor now brings back the villager's correct original personality, without the version you saved.
For mod creators

Three new functions in the public API

The editor integration uses three new functions from the AliveNpcs public API.

  • GetEditableNpcNames returns the NPCs that can get a custom personality in the current save, respecting compatibility and the AI opt-out list.
  • RegisterCustomPersonalityFile registers the editor's data file, even when its folder was renamed. The path is only accepted if the file is named custom_personalities.json.
  • GetDefaultPersonality returns the original personality, without applying the one saved by the editor.
1.4.1

New defaults and Hub polish

Jul 2, 2026

A follow-up to 1.4.0 with more useful defaults for new setups, a clear limit on how long custom LLMs can take, a scrollbar in Story Arcs and the return of NPCs from mods, now respecting the AI opt-out list.

Improved

Options that start turned on

Several options got more useful defaults for anyone starting a new configuration.

  • Multi-turn conversations now start turned on, with 3 turns of context.
  • The default Gemini model is now gemini-3.1-flash-lite.
  • Orientation discovery and romances between NPCs now start turned on.
  • The custom LLM waits up to 300 seconds by default. The maximum is 500, and the menu shows the right range, from 5 to 500 seconds.
  • Custom and OpenAI-compatible LLMs respect the 500-second cap, even when the saved setting has a higher value.
  • If you had already picked these values, yours stay. The new defaults apply to new configurations and to fields the mod corrects on its own.
  • The option help texts were updated in English, Portuguese, German, Spanish, French and Italian. So were the configuration guides in Portuguese and English.

New

NPCs from mods are back, with the AI opt-out list

SVE and NPCs from other mods are turned on by default again. Only the mods on the community AI opt-out list stay out. This part arrived in a compliance update on Jul 10, 2026.

  • AliveNpcs checks the list (AI_Mod_Exclusion.json) straight from the Stardew Modding Wiki every time the game starts.
  • You can't turn the list off. Its mods stay blocked in dialogue and in the AI systems that run in the background.
  • The block covers dialogue, festivals, relationships, letters, emotional memory, gossip reused by the AI, the weekly newspaper, the web of relationships between NPCs, and Story Arc detection and endings.
  • Until the check finishes, or if the connection fails or the list comes back broken, NPCs from mods stay blocked to be safe. Base game villagers keep working.
  • The list can name a whole mod, several mods with a wildcard or specific NPCs. For older packs that don't tie their NPCs to the mod, AliveNpcs also checks the NPCs that each installed mod on the list defines in the game.
  • The Hub shows whether the list loaded, how many rules came in, which installed NPCs it matched and why each one is blocked.
  • If you remove a mod, the history of its NPCs stays saved, but it goes dormant and doesn't feed the AI again.
Improved

Scrollbar in the Story Arcs tab

The Hub's Story Arcs tab got a visible scrollbar, in the same style as the Diary and Gossip tabs.

  • The scrollbar shows up when the list runs past the visible area, and you can drag it.
  • The mouse wheel still works.
  • Clicks outside the visible area no longer trigger hidden cards.
1.4.0

Big Party Update (Preview): festivals, hangouts and favors

Jun 29, 2026

The preview that opened the 1.4 line. Villagers got AI lines at festivals, you can ask someone to hang out, and sometimes they ask you for a favor that becomes a quest in your journal.

New

AI dialogue at festivals

A new AI dialogue system for festivals, starting with the Egg Festival.

  • At supported festivals, clicking a villager can replace the game's simple line with an in-character AI line that knows about the event. This happens when that festival's pack is active.
  • The game's original line is captured and used as an anchor for the context.
  • Festival conversations keep their context separate from everyday dialogue.
  • When the festival ends, the conversations turn into a summarized memory and a diary entry.
  • The mod recognizes the festival by the event's translated names and by temporary maps like Temp. This keeps the Egg Festival from going unnoticed.
New

Bonus actions menu

The reply menu got Bonus actions, which gathers relationship proposals, actions from EC (Experimental Content) packs and AliveNpcs' own actions.

  • The actions follow the context. If the villager or the moment in the conversation doesn't allow an action, it doesn't show up.
New

Hang out

A new action to invite a villager to spend some time with you. It shows up from 3 with that villager.

  • The invitation is social by default. A light romantic tone only comes in when the adult, romantic context allows it.
  • If the villager says yes, a short scene plays or gets ready at the agreed place, with up to 6 lines written by the AI.
  • Scene templates now have 4 or more villager lines, with longer versions for lightly romantic scenes.
  • The invitation itself can already bring reply choices for the scene, without a separate question at the end.
  • If you ask for a place that has no scene, the villager can suggest another spot. A popup asks whether you accept or refuse, and the suggested scene gets scheduled if you accept.
  • If the villager says no, they explain their reason or limit in character, and no scene happens.
  • The invitation goes into the villager's memory and can turn into gossip, unless you check Keep secret.
  • Children and child-coded NPCs never get the action or unsuitable scene templates.
  • The AliveNpcs Hub got an Outings tab, with pending invitations and a simple list of supported destinations.
  • Invitations are saved in a file of their own, invite_out_state.json.

New

Item requests

Every now and then, a villager asks for a small item in the first line of a conversation. The request becomes a regular quest in the Stardew Valley journal.

  • A request can only come up in the first eligible line, and it doesn't compete with regular lines.
  • When you hand over the item, the favor ends and a short thank-you scene may play.
  • These requests are small favors, separate from Story Arcs. They don't grow into a long questline and don't change the game's official story on their own.
  • A villager with a pending favor doesn't ask for another item.
  • Active favor quests come back to the journal when you load your save.
  • If the game already marked a favor as complete, the mod fixes its state from the quest events.
  • Requests are saved in a file of their own, item_request_favors.json.
In GMCMItem Request Chancedefault 5%. Goes from 0% to 100% for testing.
Improved

Story Arc endings on the real map

A Story Arc ending can now play on a real game map, like a regular Stardew event, with the usual sprites and speech bubbles. The black screen is only used for the title and the closing.

  • Each step of the ending has its own positions, set in JSON. This keeps the farmer and the villagers from standing on top of each other, inside walls or in the wrong spots.
  • If the ending takes you to another map, you go back to where you were when the event ends.
  • The Story Arcs menu now lets you delete saved arcs. A popup asks you to confirm first, and a message on screen confirms it afterwards.
  • The delete texts are available in English, Portuguese, German, Spanish, French and Italian.
Improved

Mayor Mode and the farm computer

The official Mayor Mode got gossip of its own, and the starting farm computer got easier to use.

  • Mayor Mode got its own instructions for the end-of-day gossip.
  • The Mayor Mode scene got translations in German, Spanish, French and Italian.
  • The starting farm computer is more compact. Clicks only work on the body of the object, and the empty tile next to it no longer opens the computer.
Improved

Safer Gemini, with support for new keys

The Gemini key no longer goes in the request address, and new keys in the AQ. format now work.

  • Regular keys go in the x-goog-api-key header, so the key never shows up in the URL.
  • Keys that start with AQ. use Gemini's interactions API, with token counting and the lowest thinking level when possible.
  • When Gemini rejects the authentication, the error now says clearly that the key is invalid.
Fixes

Fixes and stability

Day counting is right again, and empty AI replies no longer break anything.

  • Day counting was fixed in cooldowns, letters, gossip, the Hub and scenes.
  • Older saves correct the stored days for letters and for the web of relationships between NPCs when they load.
  • AI replies with empty or null fields are cleaned up before reaching the game and no longer break the flow.
For pack creators

More tools for EC packs

EC packs got new ways to shape gossip, prompts, NPCs and Story Arcs. All of it only applies while the pack's mode is active.

  • An EC can add rules to the end-of-day gossip prompt (target gossip).
  • An EC can add static or dynamic notes to the list of interactions used to generate gossip (target gossip_interaction).
  • RecordGossipInteraction lets a DLL record the day's events while the mode is active.
  • RegisterDynamicPromptBlock lets a DLL add dynamic text to the prompt at conversation time, without registering the mode again.
  • An EC can also contribute NPC personality and metadata, Story Arc templates and items, arc proposals, hooks, snapshots, dynamic button availability and experimental lore.
  • The gossip flow keeps the experimental dialogue, gossip, analysis and interaction blocks separate.
  • EC scenes now have a documented path for per-pack translations.
  • External EC packs reload the right texts when you change the game language.
  • RegisterSceneEventJson is still reserved for a future API version. For EC scenes in this preview, use sceneEventDirectories.
